# Generated Test Data Directory

This directory contains LLM-generated test datasets for validating the fact extraction pipeline.

## Directory Structure

```
generated_data/
  0001/
    blobs.jsonl          # Test blobs (one JSON per line)
    metadata.json        # Generation metadata
    analysis.json        # Test results (generated by test harness)
  0002/
    blobs.jsonl
    metadata.json
    analysis.json
  ...
```

## Usage

### Generate Test Data

```bash
# Generate 20 challenging test blobs
python scripts/generate_test_data.py --count 20 --challenging

# This creates: resources/generated_data/0002/blobs.jsonl
```

### Run Tests on All Datasets

```bash
# Scan directory and run pipeline on all datasets
python scripts/test_harness.py --scan --run-pipeline --analyze

# Run on specific dataset
python scripts/test_harness.py --dataset 0001 --run-pipeline --analyze

# Run on all datasets but skip pipeline (just analyze existing results)
python scripts/test_harness.py --scan --analyze
```

### View Results

Each dataset directory will contain:
- `blobs.jsonl` - Input test data
- `metadata.json` - Generation info (topics, model, timestamp)
- `analysis.json` - Test results (created by test harness)

## Dataset Naming

Datasets are numbered sequentially (0001, 0002, etc.) and auto-increment.
You can preserve specific datasets by copying them to a backup location.

## Best Practices

1. **Generate diverse datasets**: Mix standard and challenging topics
2. **Save important datasets**: Copy to backup before major changes
3. **Use analysis.json**: Compare results across different pipeline versions
4. **Keep metadata**: Helps track what each dataset tests
